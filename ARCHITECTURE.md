# System Architecture Document: FlashLock Engine

## 1. Tech Stack Lock

The backend uses Fastify, Redis Lua scripts, and PostgreSQL. The dashboard runs separately with Vite and React.

* **Runtime & Language:** Node.js (v22 LTS) + TypeScript 5.x (`strict: true`)
* **HTTP Framework:** Fastify v5.x (chosen for low-overhead JSON serialization and high throughput)
* **Hot-Path State & Concurrency:** Redis 7.x / 8.x via `ioredis` (using custom atomic Lua scripts via `defineCommand`)
* **Durable Ledger Database:** PostgreSQL 16+ via **Drizzle ORM** (`drizzle-orm` + `postgres` driver)
* **Schema & Payload Validation:** `zod` + `fastify-type-provider-zod`
* **Real-Time Telemetry:** Server-Sent Events (SSE) via raw Fastify streaming or `@fastify/sse`
* **Frontend Dashboard:** Vite + React + Tailwind CSS (Lightweight SPA served independently or statically)
* **Testing:** Vitest (unit, integration, and concurrent stampede tests)
